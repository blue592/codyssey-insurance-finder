### 기획 내용

| 항목 | 내용 |
| --- | --- |
| 대상 | 본인 보험정보를 관리하는 사용자 1명. PC와 모바일 사용 |
| 실행 방식 | 서버·로그인 없이 사용하는 단일 HTML |
| 대시보드 | 계약 수·보장 수·확인 필요 항목과 분류별 이동 |
| 계약별 보기 | 보험회사명·상품명·월 보험료·상세보기, 계약의 전체 보장내역 |
| 보장별 보기 | 질병·상해·운전·기타 분류와 세부 보장 탐색 |
| 신체별 보기 | 뇌·심장·치아 등의 연결 보장 탐색 |
| 등록·관리 | 증권·약관 MD 등록, 직접 확인·수정, 자동 저장, 백업·복원 |
| 후속 확장 | 질병명·진단코드와 약관을 연결하는 예상 지급보험금 계산 |

현재 기획의 금액 합계는 가입금액을 같은 보장·단위끼리 모아 보는 기능입니다. 예상 지급보험금 계산은 후속 확장으로 구분합니다.

### 완료 기준 8가지

- [ ] 단일 HTML을 열면 대시보드가 표시되고, 좁은 화면에서도 글자와 버튼이 잘리지 않는다.
- [ ] 백업 자료를 불러오면 저장해 둔 자료가 나타난다.
- [ ] 계약 목록과 상세보기의 상품명·월 보험료·계약기간·전체 보장내역이 증권과 일치한다.
- [ ] 보장별 분류에서 해당 보장을 확인할 수 있다.
- [ ] 신체별 분류에서 신체별 보장목록을 확인할 수 있다.
- [ ] 증권·약관 MD를 올리면 보험정보가 각 분류에 나타난다.
- [ ] 같은 브라우저에서 HTML을 다시 열어도 변경 내용과 변경 기록이 남아 있다.
- [ ] 백업하기를 할 수 있다.

체크박스는 검증할 기준이며, 실제 테스트를 통과했다는 표시가 아닙니다. 상세 기준은 기획서를 따릅니다.
