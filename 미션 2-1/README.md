- **PDF·CSV 결과 내보내기:** 건강정보를 항상 포함하고 저장 전에 주의 문구를 표시한다.

## 최종 확정 후 파일 정리 원칙

1. **1~4차 기획서와 관련 대화 기록은 삭제하지 않고 보존**하여 어떤 문제를 발견하고 어떻게 보완했는지 확인할 수 있도록 한다.
2. 마지막으로 확정한 기획서를 대표 **`기획서.md`**로 정리한다. 1차본은 **[기획서 초안.md](./기획서%20초안.md)**로 별도 보존했으며, 최종본은 **[기획서.md](./기획서.md)**로 새로 등록했다.
3. README에는 **최종 기획서를 가장 먼저 확인할 수 있는 링크**를 두고, 그 아래에 1~4차 기획서 파일과 대화 링크를 단계별로 유지한다.
4. **3차 `구체화기획서.md`와 3차 후속 `구체화기획서2.md`는 각각 별도 커밋으로 보관했다.** 4차 완료 기준 수정본은 `완료기준수정_기획서.md`로 별도 보관했다. 최종 확정본은 `기획서.md`이며 위의 대표 링크와 진행 상태에 반영했다.
