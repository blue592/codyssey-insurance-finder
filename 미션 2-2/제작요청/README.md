# 제작요청 대화 기록

챗지피티와 클로드에게 같은 기획서를 첨부하고 아래의 동일한 요청문으로 웹페이지 제작을 요청한 대화 내역입니다.

## 두 AI에게 전달한 요청

> 기획서대로 ‘숨은 보험금 찾기’ 웹페이지를 만들어줘. CSS와 JavaScript를 모두 HTML 파일 하나에 넣고, 다른 파일이나 로그인 없이 열리게 해 줘. 가상 인물의 정보를 쓰고, 화면 문구는 한국어로 해 줘. 기획서에 없는 기능은 넣지 마
