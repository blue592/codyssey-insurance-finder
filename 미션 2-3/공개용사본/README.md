# 예시 없는 공개용 HTML

원본과 구분하여 만든 공개용 사본이다. 보험 예시나 가상 자료를 넣지 않았고, 각 ZIP에는 HTML 파일 한 개만 들어 있다.

## 다운로드와 실행

1. 아래에서 필요한 버전의 ZIP을 선택한다.
2. 파일 화면에서 **Download raw file**로 내려받는다.
3. ZIP 압축을 풀고 안의 HTML을 브라우저에서 연다. GitHub 파일 페이지는 앱 실행 화면이 아니다.

| --- | --- | ---: | ---: |

| v4-1 | [숨은보험금찾기v4-1_public.zip](./숨은보험금찾기v4-1_public.zip) | 10.06 MB | 39.23 MB |
| v5 | [숨은보험금찾기v5_public.zip](./숨은보험금찾기v5_public.zip) | 10.07 MB | 39.26 MB |

v5_2는 요청된 파일명을 따른 것이며, 원본의 내부 v5-1 버전 표시는 그대로 남아 있다. 가장 뒤의 파일명이라고 해서 최종 제출본으로 확정된 것은 아니다.

## 변경 내용

- 개인 증권·약관을 가리키는 Space 참조 링크 3개와 연결 정보를 제거했다.
- 보험 참고 관찰자료 18건과 세대별 예시값을 모두 제거했다. 공개 상품을 사용한 샘플도 포함하며, 가상 자료로 대체하지 않았다.
- 원래 데모 기능이 있던 버전에서는 시안 체험 버튼과 가짜 보험카드·검색결과·금액을 제거했다.
- v5_1과 v5_2의 변환 요청문에서는 가상 보장 표 행과 예시 금액·납입기간 등을 제거하고 원문을 읽어 작성하라는 설명과 표 제목만 남겼다.
- 별도 브라우저 저장소를 사용하고 기존 개인용 저장소의 자동 복사를 끈다. 처음에는 빈 상태로 시작하며, 본인 자료를 직접 등록하거나 백업을 직접 불러올 수 있다. 기존 원본과 그 저장자료는 변경하지 않는다.

## 유지한 내용

- 질병코드 78,191건과 기본·삭제 코드 목록.
- 보험사명·별칭과 실손 세대 분류를 위한 공개 참고정보 및 공개 출처 14개.
- 내장 PDF·OCR·엑셀 처리 라이브러리와 사용자 등록·백업·불러오기 코드.
- v5_1과 v5_2의 증권·약관 PDF → Markdown 변환 버튼, 요청문 복사, ChatGPT 열기 링크와 사용설명 이미지.

제거한 Space 링크는 개인 파일의 참고 출처이며 변환 도구 링크가 아니다. 변환은 기존처럼 사용자가 ChatGPT에 PDF를 직접 첨부하는 방식이다. 버튼만 눌러 파일이 자동 전송되지는 않는다.

## 확인 범위

5개 사본 모두 문법·빈 초기 상태·참조 연결·질병 검색 등의 정적·함수 검사를 통과했다. 원본, 질병 데이터, 내장 라이브러리와 설명 이미지의 보존 여부를 해시로 확인했다. ZIP의 내용이 검증한 HTML 한 개와 일치하는지도 확인했다.

실행 환경의 권한 제한으로 브라우저가 시작되지 않아 실제 화면·버튼 조작 및 백업·복원 전체 흐름은 시험하지 못했다. 기능 전체가 검증되었다는 뜻은 아니다. [상세 점검 기록](../작업기록/공개용사본점검.md)
