## 완료 기준 8가지

1. 단일 HTML 실행 시 대시보드가 표시되고 좁은 화면에서도 글자와 버튼이 잘리지 않는다.
2. 백업 자료를 불러오면 저장해 둔 자료가 나타난다.
3. 계약별 목록과 상세보기의 상품명·월 보험료·계약기간·전체 보장내역이 증권과 일치한다.
4. 보장별 분류에서 질병·상해·운전·기타 및 뇌·심장·치아 등의 해당 보장을 확인한다.
5. 신체별 분류에서 신체별 보장목록을 확인한다.
6. 증권·약관 MD 파일을 올리면 보험정보가 각 분류에 나타난다.
7. 같은 브라우저에서 HTML을 다시 열어도 변경 내용과 변경 기록이 남아 있다.
8. 백업하기를 할 수 있다.
