# 최종 제출 준비

최종 버전은 아직 확정하지 않았다. 이 폴더에는 안내 문서만 있으며, 아래 제출물은 준비 대기 상태다.

| 제출물 | 예정 파일명 | 확인할 내용 |
| --- | --- | --- |
| 최종 HTML 1개 | 숨은보험금찾기.html | 수정 3건과 사용자 피드백을 반영하고 재시험한 버전 |
| 최종 기획서 | 기획서.md | 최종 HTML의 화면·동작·완료 기준과 일치 |
| 제작·검증 기록 | 제작검증기록.md | 이전 두 AI 비교·테스트 3건, 수정·재시험 3건, 사용자 1명 피드백과 반영 결과 |

- HTML은 CSS와 필요한 JavaScript를 포함한 파일 한 개로 제출한다.
- 파일을 다운로드한 뒤 브라우저에서 열어 필수 기능을 확인한다.
- 원본 버전은 수정 단계별 폴더에 보존한다.
- 실제 개인 보험정보·계약정보·첨부 원본 등 공개하면 안 되는 자료가 포함되어 있는지 확인한다.
- 대기 중인 v5_2를 최종 제출본으로 자동 지정하지 않는다.
