# 공개용 사본 변경·검증 기록

점검일: 2026-11-10

## 범위와 원본 보존

v4, v4-1, v5, v5_1, v5_2에서 각각 별도 공개용 HTML을 만들었다. 모든 원본의 SHA-256은 작업 전후 동일하다. 기존 저장소의 HTML·캡처도 수정하거나 삭제하지 않았다.

공개용 사본의 다운로드 ZIP은 [공개용사본 폴더](../공개용사본/)에 있다. ZIP 하나에는 대응하는 HTML 하나만 들어 있다.

## 제거한 자료

모든 버전에서 비활성 보험 관찰자료 18건을 제거했다. 구성은 증권·약관 기반 7건, 별도로 제공된 약관 기반 3건, 공개 상품 기반 8건이었다. 개인 파일 참조 출처 3개와 그 연결, 세대별 예시값 3개 묶음도 제거했다. 제거된 관찰자료 안의 예시값도 함께 제거되었다.

v4-1, v5, v5_1, v5_2에서는 데모 버튼과 가짜 보험자료 3행 및 대응 검색결과를 제거했다. v4에는 이 화면 데모 기능이 원래 없었다. v5 계열의 계약유형 입력 예문은 원문을 입력하라는 중립적인 안내로 바꿨다.

v5_1, v5_2의 변환 요청문에서는 가상 보장 표 행, 예시 금액·납입기간·만기 연령·계약유형과 가짜 이름을 사용한 마스킹 예문을 제거했다. 변환 설명과 원문을 채우기 위한 표 제목은 남겼다. 어떤 가상 자료도 새로 넣지 않았다.

개인 Space 참조 링크 제거는 PDF → Markdown 변환 버튼이나 ChatGPT 열기 링크의 삭제가 아니다. 변환 관련 코드와 사용설명 이미지는 유지했다.

## 저장 방식

공개용 사본마다 별도 브라우저 저장소 이름을 사용한다. 기존 개인용 저장소에서 자동으로 자료를 복사하는 코드는 제거했다. 기존 저장소는 그대로 유지되며, 사용자가 직접 자료 등록이나 백업 불러오기를 수행할 수 있다.

브라우저 실행을 시도했으나 실행 환경의 IPC 소켓 권한 제한으로 페이지를 열기 전에 종료됐다. 따라서 실제 UI와 전체 흐름이 정상이라고 단정하지 않는다. 내장된 외부 라이브러리를 원본 배포본과 전수 대조하는 공급망 감사도 수행하지 않았다.
