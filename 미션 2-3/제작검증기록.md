## 수정 기록

### 수정 기록 1. 보험 등록 기능 통합

#### 발견한 문제

첫 화면에 **증권 등록 · 약관 등록 · 내 보험 추가하기**가 각각 나뉘어 있었다. 자료를 따로 등록한 뒤 보험계약 안에 보장내역까지 하나씩 입력해야 해서 등록 과정이 번거로웠다.

#### AI에게 전달한 요청

- 분리된 등록 기능을 **‘내 보험 추가하기’ 하나로 통합**해 달라고 요청했다.
- 등록 창 안에서 **증권과 약관을 각각 업로드**하도록 요청했다.
- 업로드한 자료를 **하나의 보험계약으로 연결하고 보장내역도 함께 등록**할 수 있도록 요청했다.

#### 수정 후 테스트 결과

‘내 보험 추가하기’에서 증권과 약관을 등록하고, 하나의 보험계약으로 연결하는 방식으로 변경했다.

> **추가 확인 필요:** 연결된 보험계약에 보장내역이 누락 없이 등록되는지 확인해야 한다.

#### 수정 이유

여러 곳에서 자료와 보장내역을 따로 입력하는 불편함을 줄이고, **한 번의 등록 과정에서 보험계약과 관련 자료를 함께 관리**하기 위해 수정했다.

**버전:** [숨은보험금찾기v2.html](./1차수정/숨은보험금찾기v2.html)

### 수정 기록 2. 보험 용어 통합 DB 및 질병코드 DB 등록

#### 발견한 문제

- **암호화된 PDF 처리:** 증권과 약관을 PDF로 업로드했을 때 암호화된 파일을 열지 못했다.
- **개인정보 노출:** 원본 자료에 포함된 개인정보가 노출되는 문제가 있었다.
- **정보 추출 오류:** 보험사마다 사용하는 용어와 표현이 달라 필요한 정보를 제대로 추출하지 못했다.

#### AI에게 전달한 요청

- 암호화된 PDF 처리와 개인정보 노출 문제를 개선해 달라고 요청했다.
- 보험사별 표현을 **공통 기준으로 인식하고 추출할 수 있는 용어 통합 DB**를 만들어 달라고 요청했다.
- 질병명과 진단코드를 연결할 수 있도록 **질병코드 DB**를 등록해 달라고 요청했다.

#### 수정 후 테스트 결과

보험사별 용어를 공통 기준으로 연결하여 정보를 추출하기 위한 DB를 만들고, 질병코드 DB를 등록했다.

> **추가 확인 필요:** 암호화된 PDF 처리와 개인정보 노출 문제의 해결 여부, 실제 정보 추출 및 질병코드 연결의 정확도를 확인해야 한다.

#### 수정 이유

개인정보를 보호하면서 보험자료를 등록하고, 보험사마다 다른 표현 때문에 발생하는 **정보 추출 오류와 누락을 줄이기 위해** 수정했다. 질병명과 진단코드를 기준으로 검색할 수 있는 데이터도 마련하고자 했다.

### 수정 기록 3. 화면 재구성 및 MD 업로드 방식 적용

#### 발견한 문제

- **화면 사용의 불편함:** 기능을 쉽게 찾고 사용할 수 있도록 전체적인 배치와 이용 흐름을 정리할 필요가 있었다.
- **자료 형식의 차이:** 업로드 자료의 형식이 달라 정보를 일관되게 추출하기 어려웠다.
- **연결 기준의 불명확함:** 약관과 증권을 연결할 때 적용할 필터링 기준을 정해야 했다.

#### AI에게 전달한 요청

- 사용 편의성을 높일 수 있도록 **전체 화면 구성을 다시 정리**해 달라고 요청했다.
- 증권과 약관을 **MD 형식으로 변환한 뒤 업로드**하여 일정한 구조로 정보를 추출하도록 요청했다.
- 해당 보험계약에 맞는 약관과 증권을 연결할 수 있도록 **필터링 기준**을 정해 달라고 요청했다.

#### 수정 후 테스트 결과

전체 화면 구성을 재정리하고, MD 파일을 업로드하여 정보를 추출하는 방식으로 변경했다. 약관과 증권을 연결할 때 적용할 필터링 기준도 정했다.

> **추가 확인 필요:** 화면의 실제 사용 편의성, MD 파일의 정보 추출 정확도, 필터링 기준에 따른 약관·증권 연결 결과를 확인해야 한다.

#### 수정 이유

화면을 더 편리하게 이용하고, 자료 형식을 통일하여 **정보 추출의 일관성을 높이기 위해** 수정했다. 또한 보험계약에 맞는 약관과 증권을 연결하여 잘못된 자료가 연결되는 일을 줄이고자 했다.
