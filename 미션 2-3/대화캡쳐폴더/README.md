# 대화 캡처와 요약 모음

[**대화 타임라인 열기**](./대화타임라인.md)

- 12개 대화 묶음을 대화 시작 시각(KST) 순서로 정리했다.
- PNG 요약은 총 19장, 주제별 1~3장이다.
- 긴 원문은 짧은 공개 요약으로 연결하고 확인된 공유 대화 링크를 함께 넣었다.
- 요약 PNG는 원문 스크린샷이 아니다. 당시 진행·완료·미확인 상태를 구분했다.
- 기존 [v2 원문 캡처](../대화내역캡처/숨은보험금찾기v2._대화내역캡처.md)는 이전 경로를 유지했다.
- 다른 기존 파일은 변경·삭제하지 않았다.
