# 두 AI로 HTML 만들고 테스트하기

## 미션 소개

같은 기획서와 요청을 두 AI에 전달해 HTML을 각각 제작합니다. 두 페이지에서 같은 작업을 수행해 화면 구성과 기능을 비교하고 결과물 하나를 선택합니다. 선택한 HTML은 완료 기준에 따라 테스트하고 예상 결과와 실제 결과를 구분해 기록합니다.

## 제출 자료

- 선택한 HTML 1개: `숨은보험금찾기_v1.html`
- `제작검증기록.md`: AI 서비스·모델 이름, 동일 요청, 비교, 직접 작성한 선택 근거 1~3줄, 테스트 결과 3건
- 평가 참고 자료: 미션 2-1의 `기획서.md`
- 선택하지 않은 HTML은 제출하지 않고 설명 또는 화면 캡처로 남깁니다.

## 진행 순서

1. 두 AI에 동일한 기획서와 요청을 전달하고 서비스·모델 이름 및 실제 요청을 기록합니다.
2. 두 HTML을 각각 브라우저에서 열어 같은 작업을 수행하고 비교합니다.
3. 결과물 하나를 선택하고 선택 근거를 직접 1~3줄로 작성합니다.
4. 선택한 HTML에서 완료 기준에 따른 테스트 3건을 수행합니다.
5. 각 테스트의 내용·예상 결과·실제 결과를 기록합니다.
6. 최소 1건은 좁은 화면·빈 입력값·인쇄 등 조건을 변경합니다.
7. 각 캡처와 직접 관찰한 내용을 기록에 반영합니다. 예상과 다른 결과도 그대로 남깁니다.

## 제작 조건

- CSS와 필요한 JavaScript를 포함한 HTML 파일 하나로 구성합니다.
- 로그인·API 키·서버가 필요한 기능과 챗봇·AI 기능은 이번 제작 요청에서 제외합니다.
- 외부 자료는 사용 권한을 확인합니다. 인터넷 주소로 불러오는 자료는 다른 컴퓨터에서도 정상 표시되는지 테스트합니다.
- 한쪽 AI에만 추가 요청을 전달하지 않습니다.
- 선택 근거와 실제 테스트 결과는 사용자가 직접 판단하고 관찰한 내용을 기록합니다.
- 발견한 문제의 수정과 사용자 피드백 반영은 다음 미션에서 진행합니다.

## 현재 진행 상태

ChatGPT HTML 선택 완료. ChatGPT 자료 등록 화면과 화상 검색 결과 캡처 2건을 기록했습니다. Claude 비교와 테스트 3(조건 변경)은 대기 중입니다. 캡처를 받은 후 관찰 내용을 바탕으로 진행 상태와 기록을 갱신합니다.
