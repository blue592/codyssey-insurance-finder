# 미션 2-1 — AI와 질의응답하며 기획서 작성

## 작성 목표

AI가 먼저 질문하도록 요청하고, 질문에 답하면서 **대상 사용자, 사용 목적, 화면 구성과 동작, 필요한 자료, 완료 기준**을 구체화한다.

- 질문과 답변을 정리하여 `기획서.md`로 저장한다.
- AI가 작성한 내용 중 실제 사용 목적과 다른 부분이나 불편한 점은 직접 발견하고 수정 요청한다.
- 수정 이유와 변경 전·후의 차이를 각 버전과 대화 링크로 확인할 수 있게 기록한다.
- **사용한 AI 서비스:** ChatGPT
- **모델:** 기획서에 기록된 GPT-6 기반(정확한 세부 모델 표기는 최종 확인 예정)

## 3차 대화에서 확정한 내용

- **미청구 추정액:** 지급가능 추정액과 예상금액을 미청구 상태별로 각각 따로 합산한다.
- **가상 체험 재시작:** 기본 가상 자료만 유지하고 체험 중 입력·수정·검색 기록을 초기화한다.
- **PDF 부분 추출 실패:** 성공한 페이지는 저장하고 실패한 페이지만 수동 입력한다.
- **변경 이력 복구:** 개별 변경 선택 복구와 특정 시점 전체 복구를 지원한다.
- **PDF·CSV 결과 내보내기:** 건강정보를 항상 포함하고 저장 전에 주의 문구를 표시한다.

## 3차 후속 수정에서 확정한 내용

- **필수자료:** 첫 화면에서 보험약관·보험증권·보험정보를 직접 등록한다. 각 종류가 1건 이상 등록되기 전에는 검색 버튼과 Enter 키 검색을 사용할 수 없다.
- **체험 기능 제외:** 예제 보험자료와 별도 체험 화면·체험 파일 저장 기능을 제거한다.
- **자동저장 및 백업:** 등록·수정·삭제, 검색 기록과 책갈피를 같은 브라우저에 자동저장하고 JSON 백업·불러오기를 지원한다.
- **수정·삭제:** 등록된 약관·증권·보험정보를 수정하거나 확인 후 삭제할 수 있도록 한다.
- **검색기록 초기화:** 검색 결과·검색 기록·책갈피·검색 관련 체크와 계산 상태만 삭제하고 보험자료와 그 수정 이력은 유지한다.

## 최종 확정 후 파일 정리 원칙

1. **1~4차 기획서와 관련 대화 기록은 삭제하지 않고 보존**하여 어떤 문제를 발견하고 어떻게 보완했는지 확인할 수 있도록 한다.
2. 마지막으로 확정한 기획서를 대표 **`기획서.md`**로 정리한다. 현재 `기획서.md`는 1차본이므로, **최종본으로 교체하기 전에 1차본을 다른 파일명으로 별도 보존**한다.
3. README에는 **최종 기획서를 가장 먼저 확인할 수 있는 링크**를 두고, 그 아래에 1~4차 기획서 파일과 대화 링크를 단계별로 유지한다.
4. **3차 `구체화기획서.md`와 3차 후속 `구체화기획서2.md`는 각각 별도 커밋으로 보관했다.** 4차와 최종 확정본은 아직 만들거나 커밋하지 않았으므로, 진행한 뒤 파일명·링크·상태를 업데이트한다.
