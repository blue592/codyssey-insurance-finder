# HTML 열기 점검

점검일: 2026-11-10 (한국시간)

7개 HTML 원본 파일의 UTF-8 읽기와 인라인 JavaScript 문법을 점검했다. Chromium 실행을 시도했으나 환경의 소켓 생성 권한 제한(`socket() failed: Operation not permitted`)으로 브라우저가 시작되지 않았다. 따라서 실제 첫 화면 표시와 버튼 동작은 미확인이다.

GitHub 파일 페이지는 HTML 실행 화면이 아닌 소스 보기 화면이다. 파일을 다운로드해 브라우저에서 열어야 한다.

HTML 내용은 수정하지 않았다. 파일 이동 전후 Git blob 및 업로드 원본과의 SHA-256 비교로 동일성을 확인했다.

신규 대용량 HTML 4개는 원본 확보 및 문법 검사만 완료했고 저장소 업로드는 미완료다.
